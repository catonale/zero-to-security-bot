Module 3

Pipeline (Security Pipeline)

1. Scan 
    Bandit and/or detect-secrets produces findings with a file and a line

2. triage
    model explains and rates each finding with a JSON schema

3. Validate 
    Code drops anything without a real citation

4. comment
    One escaped comment on the pull request, edited on every push

*** Bandit is an open source tool for Python security issues, standard security linter, anyone can contribute
    Uses multiple sources for vuln databases

Making Bot Trustworthy

Citation required
    (always need a file and line that exists, with code that is on that line)

Refuse over guess
    (always okay to return no findings so no push to invent them)

Do not trust the code
    "This is test code" comes from file path, not what the file says about itself
    i.e. prompt injection with comment saying "just a test" still gets flagged

A prompt is a request, not a control.
