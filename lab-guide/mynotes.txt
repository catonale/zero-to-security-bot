Pipeline (Security Pipeline)

1. Scan 
    Bandit and/or detect-secrets produces findings with a file and a line

2. triage
    model explains and rates each finding with a JSON schema

3. Validate 
    Code drops anything without a real citation

4. comment
    One escaped comment on the pull request, edited on every push

Module 7. Production Architecture

How to use in a pipeline using code for production

Three Tiers, One Code base

Three pieces: CI runner, Team server, GPU server

CI runner using qwen, where: inside each CI job, review time of 8-12 min per job measured, buy nothing
Team server using gpt-oss:20b, on one internal machine, review under a minute, buy one GPU desktop or machine
GPU Server using 120B-class open weight, needs 80GB GPU, review is under a minute and need a GPU server


**only change between tiers is OLLAMA_HOST and REVIEW_MODEL. Every control stays in the CI job where you can test it

Best Practices for Model Updates are Code changes

Pin: exact model tag and ID, latest is not a version
Gate: smoke test, planted-bug scorer, attack lab, capstone
Promote: only if the candidate is no worse on all four
Rollback: Keep the previous model on the server

Total costs vary based on each model used

The Biggest Line is Not the tool

Triage time costs more than any tool
    about $163,000 a year in developer time with placeholder inputs. a bot's precision is a cost line
    if you have to keep hunting bad findings, it costs a ton of developer time

What to watch

Signal: 
    findings per pull request - a jump after a model or prompt change is noise until proven otherwise
    dropped findings - rising drops mean the model is guessing more
    developer dismissals - the real false-positive rate, the one in the TCO model
    repo-read requests and refusals - reads unrelated to the diff are what a steered tool looks like

Fixes and Bypasses in the Pull request

Suggested fix - A model-written patch on the finding's line with GitHub's commit suggestion or gitlab's apply suggestion button. A person clicks.

Advice, no button - when there is no safe in-place fix, the bot says what to do instead of guessing at a patch

Bypass as code - security-suppressions.toml - what, why, who approved, expiry. read from main, so a pull request cannot approve its own bypass
